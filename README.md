# MasterWingJack
Martial arts website

This project is supposedly a martial arts website. it contains information pertaining to a certain martial arts client, 'MasterWingJack'.

The client had certain requirements such as the pages to be added, the certain objectives to be accomplished and the general look/feel of the website.
The website is coded using python language, HTML, CSS, a bit of Javascript for functionality and features will continue to be added as the project continues.

Not gonna lie, this is my first project hoping to see what i have learnt over the days.

Objectives
- Give the client an immediate desire to set up an apointment
- Get prospects to send their contact information
- Educate prospects about the school

The various pages added include:
  Home, About, Programs, Resources, Gallery, Contact Us.

For now the main focus is on the front end as i work my way to the backend hoping to fully deliver the needs of the client.
